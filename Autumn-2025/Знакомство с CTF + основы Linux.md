## О CTF

**Захват Флага** (англ. Capture The Flag) — это соревнования по спортивному хакингу, в которых «флаги» тайно прячутся в преднамеренно уязвимых программах или веб сайтах. Участники крадут флаги либо у других участников (CTF в стиле атаки/защиты), либо у организаторов (испытания в стиле Jeopardy). Существует несколько вариантов. Соревнования могут включать в себя скрытие флагов в аппаратных устройствах, они могут быть как онлайн, так и офлайн, а также могут быть продвинутыми или начального уровня.

CTF традиционно проходит в двух форматах:
- **Jeopardy** (Task-based)
	В этом формате участникам предлагается решить набор задач из различных категорий, таких как Web, Cryptography, Reverse, Pwn, OSINT, Forensics, Steganography, PPC, Misc. За решение каждой задачи даются очки. Побеждает тот, кто наберёт наибольшее количество очков.
- **Attack-Defense**
	Участникам выдается набор заведомо уязвимых сервисов, после чего у игроков есть час на знакомство с исходным кодом приложений на предмет поиска уязвимостей. По истечению времени, запускается проверяющая система, имитирующая обычных пользователей, которая следит за работоспособностью сервисов у каждой команды. Цель: найти и исправить уязвимости в приложениях, а также написать эксплойты для кражи флагов у других команд.

#### Bandit 0

Просят подключиться по *ssh* на ***bandit.labs.overthewire.org*** на порт 2220. Креды для подключения `bandit0:bandit0`. 

**SSH (Secure SHell - защищенная оболочка)** — сетевой **протокол** прикладного уровня, предназначенный для безопасного удаленного доступа к различным системам. Данный протокол шифрует всю передаваемую информацию по сети.

[Мануал](https://manpages.ubuntu.com/manpages/noble/man1/ssh.1.html) по команде `ssh`, также можно ввести `man ssh`.

Подключаемся командой `ssh bandit0@bandit.labs.overthewire.org -p 2220`

#### Bandit 1

Пароль для следующего уровня хранится в файле **`-`** в домашней директории.

Для просмотра содержимого файла в линуксе используется команда `cat`. В мире Linux символ `-` имеет особое значение: для многих команд он представляет **стандартный поток ввода (stdin)**, а не файл. Поэтому для просмотра этого файла нужно использовать специальный синтаксис: `cat ./-` или `cat -- -`.

#### Bandit 3

Пароль для следующего уровня хранится в спрятанном файле в директории **`inhere`**.

Для вывода содержимого папки используется команда `ls`. По умолчанию, эта команда не отображает скрытые файлы. Воспользовавшись `man ls` или `ls --help`, находим флаг **`-a`**. Выполнение `ls -a` выведет **все** файлы в данной директории, в том числе и скрытые.
